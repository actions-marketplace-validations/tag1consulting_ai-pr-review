# v2.18.0

## Added

- **The weekly model watcher now covers OpenAI and Google as well as Anthropic.** `model-watch.yml` (Mondays 10:00 UTC, or on demand with an optional dry run) lists the models each provider offers and opens one issue per model that is newer than a pinned default. It never changes a default. OpenAI and Google are checked when the `OPENAI_API_KEY` and `GOOGLE_API_KEY` repository secrets are set, and a provider without a secret is skipped. OpenAI renames tiers between versions (GPT-5.6 had `luna` / `terra` / `sol`, GPT-6 has `luna` / `sol` / `astra`), so the watcher also reports any model in a newer version whose tier neither default uses. For Google it watches stable Flash-Lite and Flash models, and also reports a stable Gemini Pro for the premium slot. Previews and `-tts`, `-live` or `-image` variants are never reported.

## Changed

- **Behavior change: the default Google models are now `gemini-3.5-flash-lite` (standard) and `gemini-3.8-flash` (premium)** (were `gemini-2.5-flash` / `gemini-2.5-pro`). Google now serves the 2.5 models only to projects that have used them before, so a new project could not call the old defaults. There is no stable Gemini 3.x Pro model, so the premium default is a Flash model. Gemini 3 models now get `thinkingConfig.thinkingLevel: low` (except Flash-Lite, whose default is lower), because the default level used up to 30,938 thinking tokens on the stress diff against a 32,768-token output limit that includes thinking. Temperature is omitted for them, as Google advises. `gemini-3.8-flash` is priced at its 2027-01-01 rate ($1.50 / $7.50 per MTok), not its introductory rate ($0.75 / $3.75 through 2026-12-31), so cost estimates and `AI_MAX_COST_USD` never under-count. To keep the previous models, set `AI_MODEL_STANDARD=gemini-2.5-flash` and `AI_MODEL_PREMIUM=gemini-2.5-pro`.
- **Behavior change: the default OpenAI models are now `gpt-6-luna` (standard) and `gpt-6.1-sol` (premium)** (were `gpt-5.4-mini` / `gpt-5.4`). Both are cheaper: $0.10 / $0.50 and $2 / $10 per MTok, against $0.75 / $4.50 and $2.50 / $15. Temperature is omitted for `gpt-5.6*` and `gpt-6*`, and pricing rows cover every GPT-5.6 and GPT-6 model, so a user who picks one of them keeps the `AI_MAX_COST_USD` ceiling. OpenAI reasoning tokens are now shown as thinking tokens. To keep the previous models, set `AI_MODEL_STANDARD=gpt-5.4-mini` and `AI_MODEL_PREMIUM=gpt-5.4`.
- **Both default changes were verified with the live model canary** on the 1200-line stress diff: 4 of 4 calls per provider finished cleanly, each with a valid findings block, and the review text was read, not only the stop reason. Not verified: review quality on other diffs, and whether GPT-6 rejects an explicit temperature (none was sent).
- **The live model canary can now test OpenAI, Google and `bedrock-proxy`** when their keys are set. It fails a response whose findings block is missing or is not a JSON array, reports findings, output tokens and time per call, and saves each review's text when `CANARY_OUTPUT_DIR` is set.

The `bedrock-proxy` and Anthropic defaults are unchanged.

See [CHANGELOG.md](https://github.com/tag1consulting/ai-pr-review/blob/main/CHANGELOG.md) for full technical detail.
