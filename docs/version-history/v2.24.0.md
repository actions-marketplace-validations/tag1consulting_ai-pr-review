# v2.24.0

## Added

- **A provider "prompt too long" rejection now skips the review (#1056).** The pre-flight estimate can be too low. Before, the provider rejected the prompt with an HTTP 400, every agent failed, and the comment said "0 findings, 2 failed agents". Now the engine stops and posts a skip comment that names the agent, the model, and `AI_EXCLUDE_PATTERNS`. The comment also carries the analyzer and SARIF findings, and the run does not advance the watermark. `AI_FAIL_ON_CONTEXT_WINDOW=true` makes this skip exit with code 2. Only the Anthropic message text is matched. If only some agents are rejected, the review continues and the failed-agent note says so.
- **Bitbucket: the `/ai-pr-review feedback [F<n>] <text>` command (#933).** The text is required and an `F<n>` is optional. The command uses the same authorization as `false-positive` and `wont-fix`. It writes to the learning-loop store only when `AI_FEEDBACK_LOOP=true` and `AI_BITBUCKET_VERDICTS=true`. See [Slash commands](../slash-commands) and [Bitbucket setup](../bitbucket-setup#dismissing-findings).
- **The `COST_ESTIMATE` log line ends with `input=` and `output_cap=` (#1055).** Use them to see how much of the estimate is the worst-case output cap. The configuration page has a worked example. See [Configuration](../configuration).

## Changed

- **Behavior change: the severity icons are different shapes (#1037).** Critical is ⛔, High is 🚨, Medium is 🔶, and Low is 💬. 🚨 meant Critical before and means High now. A review comment that was posted before the upgrade keeps its old icon until the next review rewrites it. No parser reads the icon. See [Agents](../agents).
- **The `also_reported` notes are capped only when they are shown (#1047).** The first 5 notes are shown, with a "(+N more from other analyzers)" line. The count is now correct when a cluster has more than 5 notes.
- **The example workflows pass `approval-ceiling` (#1064).** `vars.AI_REVIEW_APPROVAL_CEILING` now reaches the action, so an organization-level variable covers every repository that copies the example.
- **The phpcs analyzer code is split (#1047).** Behavior is unchanged. The security canary has a symlink case and a test with the real phpcs.
